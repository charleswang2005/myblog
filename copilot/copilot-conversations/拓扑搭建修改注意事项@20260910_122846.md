
设备在本地用户表里找不到 `aaa` 这个用户，AAA 模块无法发起认证请求，所以报的是 **Failed to send authen-req**（认证请求发不出去），而不是"密码错误"。真正密码错误时提示会是 `Error: Username or password is invalid.` 之类的。所以这条报错基本可以等同于"**该用户名在本地不存在**"。

## 正确操作

退出后重新登录，输入：

```
Username:abc
Password:123123
```

就能进入 `<Huawei>`，`display current-configuration` 里能看到用户 abc 的权限是 level 15。

## 可以顺手核对一下

```
<Huawei>display aaa local-user
```

或

```
<Huawei>display current-configuration | include local-user
```

确认本地用户表里确实是 `abc`，而不是 `aaa`（如果你本来就想用 aaa 当用户名，那就重新建一个 `local-user aaa ...` 即可）。

## 另外两点提醒

- Console 认证模式从 `password` 改成 `aaa` 后，之前设的 `123456` 就失效了，只能用"本地用户名 + 密码"登录，这是正常的。
- eNSP 的串口窗口偶尔会丢字符（看你前面 `conslode`、`loca`、`privil` 那些残行就是输入被打断造成的），建议把命令整行复制粘贴进串口窗口，再按回车，比一个个字母敲稳。
