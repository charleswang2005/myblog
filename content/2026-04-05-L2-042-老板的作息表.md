新浪微博上有人发了某老板的作息时间表，表示其每天 4:30 就起床了。但立刻有眼尖的网友问：这时间表不完整啊，早上九点到下午一点干啥了？

本题就请你编写程序，检查任意一张时间表，找出其中没写出来的时间段。

#### 输入格式

输入第一行给出一个正整数&nbsp;，为作息表上列出的时间段的个数。随后&nbsp;&nbsp;行，每行给出一个时间段，格式为：

hh:mm:ss - hh:mm:ss

其中&nbsp;、、&nbsp;分别是两位数表示的小时、分钟、秒。第一个时间是开始时间，第二个是结束时间。题目保证所有时间都在一天之内（即从 00:00:00 到

23:59:59）；每个区间间隔至少&nbsp;&nbsp;秒；并且任意两个给出的时间区间最多只在一个端点有重合，没有区间重叠的情况。

#### 输出格式

按照时间顺序列出时间表中没有出现的区间，每个区间占一行，格式与输入相同。题目保证至少存在一个区间需要输出。

#### 样例

**样例输入**

```
8
13:00:00 - 18:00:00
00:00:00 - 01:00:05
08:00:00 - 09:00:00
07:10:59 - 08:00:00
01:00:05 - 04:30:00
06:30:00 - 07:10:58
05:30:00 - 06:30:00
18:00:00 - 19:00:00

```

**样例输出**

```
04:30:00 - 05:30:00
07:10:58 - 07:10:59
09:00:00 - 13:00:00
19:00:00 - 23:59:59
```

```
#include 
using namespace std;
set>record;
string work_starttime,work_endtime,last="00:00:00";
int main() {
	int n;
	cin>>n;
	while(n--)//输入n组数据 
	{
		string dash;//平衡两组输入中间的'-' 
		cin>>work_starttime>>dash>>work_endtime;//用字符串来记录开始时间和结束时间 
		record.insert({work_starttime,work_endtime});//set能够自动实现去重和排序（按字典序） 所以用set
		                                              //record.insert({})插入时间段 
	}
	for(auto i:record)//输入好所有数据 人很容易一眼看出来 但是计算机怎么识别呢？ 
	{
		if(last<i.first)//加一个起始位置last''000000'' 就可以看出last-第一个开始时间段有没有间隔 如果小于 则有间隔 
		{
			cout<<last<<" - "<<i.first<<endl;//输出间隔时间段 
		}
		last=i.second;//更新状态 从000000到第一个结束都是满的 
	
	}
		if(last<"23:59:59")//最后输出的时候发现少了最后到24点的那一段 因为last最后更新是到最后一段的结束点 而不是000000
		                   //所以对这一段单独处理  
		{
			cout<<last<<" - "<<"23:59:59"<<endl;
		}
    return 0;
}
```
