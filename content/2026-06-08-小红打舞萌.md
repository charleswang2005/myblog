小红正在打舞萌。
\hspace{15pt}小红拥有 xx 枚游戏币。对于每次游玩，小红可以选择自己玩，花费 55 枚游戏币玩 33 首歌；或者和别人一起玩，花费 55枚游戏币玩 44 首歌。但小红无法在连续两次游玩中都选择和别人一起玩。请你计算小红最多可以玩多少首歌。

## 输入描述:

```
\hspace{15pt}第一行输入一个整数 x(1≤x≤109)x\left(1 \leq x \leq 10^9 \right)x(1≤x≤109)。
```

## 输出描述:

```
\hspace{15pt}输出一个整数，代表小红最多可以玩多少首歌。
```

示例1

## 输入

```
11
```

## 输出

```
7
```
