## 题目描述

如果一个正整数只能被&nbsp;1&nbsp;和它本身两个数整除，就称为一个质数。最小的几个质数依次是&nbsp;2,3,5,7,11,13,⋯

请问，第&nbsp;2025&nbsp;个质数是多少？

## 输入格式

无

## 输出格式

这是一道结果填空的题，你只需要算出结果后提交即可。本题的结果为一个整数，在提交答案时只需要**编写一个程序输出这个整数**，输出多余的内容将无法得分。

## 输入输出样例

无

```
#include 
using namespace std;
const int N = 501; 
int A[N][N],s[N][N];
bool jd(int a)//素数判断函数 
{
	if(a==1) return false;//1不是素数  
	if(a==2) return true;//2是素数 
	if(a%2==0) return false;//偶数肯定不是素数 直接排除提高效率 
	for(int i=2;i*i<=a;i++)//只需要找到2-√a即可 
	{
		if(a%i==0)
		{
			return false;
		}
	}
	return true;//是素数 
}
int main() {
	int ans=0;//记录 
	for(int i=1;;i++)
	{
		if(jd(i))
		{
			ans++;//找到一个+1 
		}
		if(ans==2025)//第2025个直接输出 
		{
			cout<<i<<endl;
			return 0;
		}
	}
    return 0;
}

```
