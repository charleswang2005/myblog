# 第一章、思考题
1、简述HTTP的请求/响应模型；
答：HTTP 遵循请求/响应模型：客户端（浏览器）向服务器发送请求（含请求行、请求头、请求正文），服务器处理请求后返回响应（含响应行、响应头、响应正文），完成一次通信。
7.Brup Suite 主要的部件有哪些？分别有什么功能？
Burp Suite 主要包含 8 个组件：
1.  Proxy：拦截、修改 HTTP/HTTPS 数据包。
2.  Spider：爬取网站目录与链接。
3.  Scanner：自动扫描漏洞（仅专业版）。
4.  Intruder：自动化枚举、爆破与模糊测试。
5.  Repeater：重放并修改数据包，分析响应。
6.  Sequencer：分析 Token 随机性质量。
7.  Decoder：编码/解码（URL、Base64 等）。
8.  Comparer：对比两个字符串或文件的差异。
