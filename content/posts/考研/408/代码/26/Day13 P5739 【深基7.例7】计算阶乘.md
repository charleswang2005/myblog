## 题目描述

求 $n!$，也就是 $1\times2\times3\dots\times n$。

挑战：尝试不使用循环语句（for、while）完成这个任务。

## 输入格式

第一行输入一个正整数 $n$。

## 输出格式

输出一个正整数，表示 $n!$。

## 输入输出样例 #1

### 输入 #1

```
3
```

### 输出 #1

```
6
```

## 说明/提示

数据保证，$1 \leq n\le12$。
