## 题目描述

有一个 $n(n \le 10^6)$ 个结点的二叉树。给出每个结点的两个子结点编号（均不超过 $n$），建立一棵二叉树（根节点的编号为 $1$），如果是叶子结点，则输入 `0 0`。

建好这棵二叉树之后，请求出它的深度。二叉树的**深度**是指从根节点到叶子结点时，最多经过了几层。

## 输入格式

第一行一个整数 $n$，表示结点数。

之后 $n$ 行，第 $i$ 行两个整数 $l$、$r$，分别表示结点 $i$ 的左右子结点编号。若 $l=0$ 则表示无左子结点，$r=0$ 同理。

## 输出格式

一个整数，表示最大结点深度。

## 输入输出样例 #1

### 输入 #1

```
7
2 7
3 6
4 5
0 0
0 0
0 0
0 0
```

### 输出 #1

```
4
```
## 代码
```C++
#include <bits/stdc++.h>
using namespace std;
#define int long long
struct node//树结构
{
    int l;
    int r;
}a[1000000+10];
int h=-1;
void dfs(int node,int cnt)//搜索树 第i个节点 第j层
{
    if(a[node].l==0&&a[node].r==0) 底部叶子节点 更新深度
    {
        h=max(h,cnt);
    }
    if(a[node].l!=0) dfs(a[node].l,cnt+1);//非叶子节点优先访问左子树 再右子树
    if(a[node].r!=0) dfs(a[node].r,cnt+1);//是cnt+1 而非cnt++
}
signed main()
{
    int n;
    cin>>n;
    for(int i=1;i<=n;i++)
    {
        cin>>a[i].l>>a[i].r;
    }
    dfs(1,1);
    cout<<h;
    return 0;
}
```
