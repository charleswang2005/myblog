## 题目描述

给定一个十进制整数 $n$ 和一个小整数 $x$。将整数 $n$ 转为 $x$ 进制。对于超过十进制的数码，用 `A`，`B` ... 表示。

## 输入格式

第一行一个整数 $n$；

第二行一个整数 $x$。

## 输出格式

输出仅包含一个整数，表示答案。

## 输入输出样例

### 输入

```
1000
2

```

### 输出

```
1111101000

```

## 说明/提示

【数据规模和约定】  
保证 $n$ 不超过 $10^9$，$x$ 不超过 $36$。
## 代码
```C++
#include <bits/stdc++.h>
using namespace std;
#define int long long
char sta[40];
int top=0;
int n;
int x;
signed main()
{
	cin>>n>>x;
	while(n>=x)
	{
		int t=n%x;
		n/=x;
		if(t>=10) sta[top++]=t-10+'A';
		else sta[top++]=t-0+'0'; 
	}
	if(n>=10) sta[top]=n-10+'A';
	else sta[top]=n-0+'0';
	while(top>=0)
	{
		cout<<sta[top];
		top--;
	}
	cout<<endl;
    return 0;
}
```
