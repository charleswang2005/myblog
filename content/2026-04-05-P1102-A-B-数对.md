## 题目背景

出题是一件痛苦的事情！

相同的题目看多了也会有审美疲劳，于是我舍弃了大家所熟悉的 A+B Problem，改用 A-B 了哈哈！

## 题目描述

给出一串正整数数列以及一个正整数&nbsp;*C*，要求计算出所有满足&nbsp;*A*−*B*=*C*&nbsp;的数对的个数（不同位置的数字一样的数对算不同的数对）。

## 输入格式

输入共两行。

第一行，两个正整数&nbsp;*N*,*C*。

第二行，*N*&nbsp;个正整数，作为要求处理的那串数。

## 输出格式

一行，表示该串正整数中包含的满足&nbsp;*A*−*B*=*C*&nbsp;的数对的个数。

## 输入输出样例

**输入 #1**复制

```
4 1
1 1 2 3
```

**输出 #1**复制

```
3
```

## 说明/提示

对于&nbsp;75%&nbsp;的数据，1≤*N*≤2000。

对于&nbsp;100%&nbsp;的数据，1≤*N*≤2×105，0≤*a**i*​&lt;230，1≤*C*&lt;230。

```
#include 
using namespace std;
const int N = 200010; 
int s[N];
#define int long long
signed main() {
    int n, c;
    cin >> n >> c;
    int ans = 0;
    for(int i = 0; i > s[i];
    }
    sort(s, s + n); // sort排序
    // a 是右端点，b 是满足条件的左端点起点
    //B=A-C A是大的数 所以b一直在a的后面 
    for(int a = 0, b = 0; a  c) {
            b++;
        }
        //a=1---a=2 b++=1 b移动是因为数太小了 
        // 2. 如果找到了一个满足条件的 b
        if(s[a] - s[b] == c) {
            // 【核心修改】：往后数，有多少个和 s[b] 一样的数
            int temp = b; 
            // 只要 temp 没越界，且数字还等于 s[b]，就计数
            while(temp < a && s[temp] == s[b]) {
                ans++;
                temp++;
            }
        }
    }
    //最后有一个测试点过不了 用二分可以过 
    cout << ans << endl;
    return 0;
}
```
