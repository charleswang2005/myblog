## 题目描述

小蓝有&nbsp;*n*&nbsp;个装了水的瓶子，从左到右摆放，第&nbsp;*i*&nbsp;个瓶子里装有&nbsp;*a**i*​&nbsp;单位的水。为了美观，小蓝将水循环染成了&nbsp;*k*&nbsp;种颜色，也就是说，第&nbsp;*i*&nbsp;个瓶子和第&nbsp;*i*+*k*&nbsp;个瓶子里的水的颜色相同。

小蓝发现有的瓶子里的水太少了，因此他规定如果第&nbsp;*i*&nbsp;个瓶子和第&nbsp;*j*&nbsp;个瓶子中的水颜色相同并且满足&nbsp;*i*&lt;*j*，即可将任意整数单位的水从第&nbsp;*i*&nbsp;个水瓶倒出，倒入第&nbsp;*j*&nbsp;个水瓶中。小蓝想知道任意次操作后所有瓶子中的水的最小值&nbsp;min{*a**i*​}&nbsp;最大可以是多少？

## 输入格式

输入的第一行包含两个正整数&nbsp;*n*,*k*，用一个空格分隔。

第二行包含&nbsp;*n*&nbsp;个正整数&nbsp;*a*1​,*a*2​,⋯,*a**n*​，相邻整数之间使用一个空格分隔。

## 输出格式

输出一行包含一个整数表示答案。

## 输入输出样例

**输入 #1**复制

```
7 3
8 5 5 2 2 3 4
```

**输出 #1**复制

```
3
```

## 说明/提示

### 样例说明

其中一种方案：

- *a*1​&nbsp;往&nbsp;*a*4​&nbsp;倒入&nbsp;3&nbsp;单位；

- *a*2​&nbsp;往&nbsp;*a*5​&nbsp;倒入&nbsp;2&nbsp;单位；

- *a*3​&nbsp;往&nbsp;*a*6​&nbsp;倒入&nbsp;1&nbsp;单位； 最终每个瓶子里的水：5,3,4,5,4,4,4，最小值为&nbsp;3。
