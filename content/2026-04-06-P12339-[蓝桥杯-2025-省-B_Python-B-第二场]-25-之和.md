## 题目描述

小蓝最近对求和很着迷，给定一个正整数&nbsp;*n*，他想求从&nbsp;*n*&nbsp;开始的连续&nbsp;25&nbsp;个整数的和，即&nbsp;*n*+(*n*+1)+(*n*+2)+⋯+(*n*+24)，请帮帮他吧。

## 输入格式

输入一行包含一个正整数&nbsp;*n*。

## 输出格式

输出一行包含一个整数表示答案。

## 输入输出样例

**输入 #1**复制

```
1
```

**输出 #1**复制

```
325
```

**输入 #2**复制

```
100
```

**输出 #2**复制

```
2800
```
