## 题目描述 [](javascript:void(0)) [](javascript:void(0);)

\hspace{15pt}给定一个长为 44 的字符串 ss，请你计算在这个字符串中有多少个字符恰好出现了一次。

## 输入描述:

```
\hspace{15pt}第一行输入一个长为 4 的字符串 ss，保证 ss 仅包含小写字母。
```

## 输出描述:

```
\hspace{15pt}输出一个整数，代表答案。
```

示例1

## 输入

xcpc

## 输出

2

```
#include 
using namespace std;
const int N = 501; 
#define int long long
signed main() {
	string s;
	cin>>s;
	int sum=0;
	char zm[27]={0};//创建一个数组用来存放每个字母出现的次数 
	for(int i=0;s[i];i++)
	{
		int x=0;
		x=s[i]-96;//a的阿斯克玛是97 
		zm[x]++;
	}
	for(int i=1;i<=26;i++)
	{
		if(zm[i]==1)
		{
			sum++;//统计只出现一次的字母的个数 
		}
	}
	cout<<sum<<endl;
    return 0;
} 
```
